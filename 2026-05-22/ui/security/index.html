보안

보안의 경계를 분명히 밝힙니다.

이 사이트가 브라우저에 저장하는 것, 외부 서비스로 연결되는 것, 사용자가 직접 관리하는 것을 구분해 안내합니다.

Security model Local-first control

비밀번호 같은 민감한 정보는 사이트가 직접 저장하지 않으며, 알림과 저장소는 브라우저 권한을 따릅니다.

브라우저 저장소

테마, 언어, 활동 기록, 구독 정보는 이 브라우저의 로컬 저장소에만 보관됩니다.

쿠키

필수 기능과 저장 안내 확인용 쿠키만 사용합니다. 광고·분석 쿠키는 현재 사용하지 않습니다.

알림

회원 전용 새 소식은 사이트 안에서만 표시되며 브라우저 알림 권한을 사용하지 않습니다. Windows·모바일 푸시 알림은 현재 연결되어 있지 않습니다.

피드백 양식

피드백 양식에는 외부 서비스의 정책이 적용되므로, 민감한 개인정보는 입력하지 않는 것을 권장합니다.

문제 신고

보안이나 개인정보 관련 문제를 발견하시면 피드백으로 알려 주세요.
