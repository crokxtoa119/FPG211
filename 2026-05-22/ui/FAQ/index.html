FAQ

미국에서 EMT가 되는 방법

주마다 규정은 다르지만, 일반적으로 EMT 교육을 이수하고 시험에 합격한 뒤 주 면허를 신청합니다.

1. EMT와 Paramedic은 어떻게 다른가요?

EMT는 기본 응급처치를 담당하는 첫 단계입니다. Paramedic은 더 긴 교육을 거쳐 약물 투여, 심전도 판독, 고급 기도 관리 같은 전문 처치를 수행합니다.

2. 시작하려면 무엇이 필요한가요?

대부분 고등학교 졸업장 또는 GED, CPR/BLS 자격, 신원 조회, 예방접종 기록을 요구합니다. 학교와 주마다 다르므로 지원 전에 꼭 확인하세요.

3. EMT가 되기까지의 과정은?

주에서 인정한 EMT 과정을 이수하고 실습을 마친 뒤, NREMT 같은 시험에 응시합니다. 합격 후 근무할 주에 면허를 신청합니다.

4. Paramedic이 되려면 얼마나 걸리나요?

EMT 이후 보통 1~2년의 추가 교육이 필요합니다. 학교에 따라 임상 실습, 구급차 실습, 국가 시험이 포함됩니다.

5. 면허는 주마다 다른가요?

그렇습니다. 인증 시험에 합격하더라도 실제로 근무하려면 해당 주의 면허가 필요합니다. 다른 주로 옮길 때는 추가 요건을 확인하세요.

6. 무엇을 준비하면 좋을까요?

체력, 소통 능력, 침착함, 팀워크가 중요합니다. 환자 개인정보 보호와 지역 응급의료 규정도 함께 익혀 두면 좋습니다.

FAQ

게임 개발, 어떻게 시작할까요?

1. 처음에는 무엇을 만들면 좋을까요?

작은 게임 하나를 끝까지 완성해 보세요. Unity, Godot, Roblox Studio 중 도구 하나를 정하고 이동, 충돌, 점수, UI부터 익히는 것을 권합니다.

2. 어떤 언어부터 배워야 하나요?

Unity는 C#, Unreal은 C++, Godot은 GDScript 또는 C#, Roblox는 Lua를 주로 사용합니다. 처음에는 엔진 하나와 언어 하나에 집중하는 것이 좋습니다.

3. 포트폴리오에는 무엇을 담아야 하나요?

완성한 작은 게임, 플레이 영상, 직접 구현한 기능, 해결한 문제를 담으세요. 아이디어보다 직접 플레이할 수 있는 결과물이 더 큰 설득력을 가집니다.

4. 혼자 개발해도 괜찮을까요?

물론입니다. 혼자 만들어 보면 전체 과정을 이해하기 쉽습니다. 이후 작은 팀 프로젝트로 협업 경험을 쌓아 가세요.

FAQ

연락하거나 만날 수 있나요?

1. 직접 만날 수 있나요?

먼저 온라인으로 연락해 주세요. 직접 만남은 목적, 일정, 장소, 안전 기준이 분명한 경우에 한해 별도로 논의합니다.

2. 어디로 연락하나요?

Feedback 페이지로 문의해 주세요. 급하지 않은 내용이라면 목적과 필요한 정보를 함께 적어 주시면 됩니다.

FAQ

사이트 이용과 운영

1. 사이트는 어떻게 배포하나요?

파일을 GitHub에 올리고 Vercel에 연결하면 됩니다. 정적 사이트이므로 Root Directory만 맞으면 별도 빌드 없이 배포됩니다.

2. 문의는 어디로 하나요?

피드백 페이지를 이용해 주세요. 문의 목적과 필요한 정보를 간단히 적어 주시면 됩니다.

3. 피드백은 어떻게 보내나요?

피드백 페이지의 Google Forms 버튼으로 보내실 수 있습니다. 오류, 개선 아이디어, 불편한 점 무엇이든 좋습니다.

4. Codex로 사이트를 개발할 수 있나요?

네. Codex로 HTML, CSS, JavaScript 사이트를 만들고 디자인 수정, 페이지 추가, 모바일 확인, 배포 전 점검까지 할 수 있습니다. 다만 결제, 로그인, 개인정보 처리 기능에는 별도의 보안 설계와 외부 서비스 설정이 필요합니다.

5. 개인정보는 어떻게 처리되나요?

테마, 언어, 표시 설정 같은 정보는 브라우저에만 저장됩니다. Google 로그인은 Firebase Authentication이, 양식에 입력한 내용은 Google Forms가 처리합니다. 자세한 내용은 개인정보 처리방침을 참고해 주세요.
